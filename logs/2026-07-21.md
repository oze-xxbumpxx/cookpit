## 気づき・メモ

- **CI audit の構造（重要・再利用知見）**: `ci.yml` の audit ジョブは
  `pnpm install --frozen-lockfile` を **pnpm 10** で走らせて lockfile（＝依存ツリー）を確定し、
  その後 `pnpm audit` だけ **pnpm 11** に差し替える設計（npm legacy audit API 410 廃止対応）。
  したがって override は **package.json の `pnpm.overrides` のまま**でよい（pnpm 10 install が
  解決する）。pnpm 11 は package.json の `pnpm` フィールドを読まず warning を出すが、audit は
  lockfile を読むだけなので影響しない。→ **pnpm-workspace.yaml へ移す必要はなかった**。
- 推移依存の advisory は「コード無変更でも突然 CI が赤くなる」典型。main の緑は再実行前の
  スナップショットに過ぎない点に注意（#87/#88 も未更新なら赤の可能性）。
- **持ち越し（open のまま合意済み）**: #88 / #87（Dependabot）は fix 前 base のため Audit 赤の
