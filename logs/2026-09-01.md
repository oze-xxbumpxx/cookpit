## 気づき・メモ

- **「継続費用なし」制約の射程を切り分けた。** `docs/01-overview.md` の制約が排除しているのは
  EC2/RDS 型の**常時課金**であり、Bedrock オンデマンドは従量課金のみで文言の趣旨には反しない。
  ただし ADR 化するなら、この読み替えを明記しないと後から矛盾に見える。
- **費用の「止め方」が Bedrock と Anthropic API で構造的に違う。** Anthropic API は前払い
  クレジット制でオートリロードを切れば入金額がハード上限。AWS は後払いで、Budgets は
  アラートのみで遮断しない。「費用が気になる」への直接の答えは前者。
- **Bedrock は Structured outputs 非対応**（Messages-API エンドポイント。Batch / server-side tools も非対応）。
  本プロジェクトは `packages/api-contract` が Zod なので、直の API なら `output_config.format` と
  素直に噛み合う。Bedrock だとパース失敗時のリトライを自前で書く必要がある。
- **LLM 化しても前提条件は変わらない。** レシピ 6 件では提案が成立しない点は Bedrock でも
  Anthropic API でも同じ。ロードマップの「レシピ移行が前提」が先に効く。
- **リモート環境の事実: `aws.amazon.com` が egress プロキシでブロックされる。**
  Bedrock の正確な単価は AWS 側の別体系だが、この環境からは公式料金ページに到達できず未検証。
  `platform.claude.com` は到達可能。`docs/07-dev-rules.md` §環境の既知の事実 への追記候補
  （2026-08-21 の「dev では SW が登録されず Push を検証できない」と同じクラスの事実）。
