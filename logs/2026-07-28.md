## 気づき・メモ

- **ハーネスが自分自身の修正を拒否するデッドロックを実地で踏んだ。** `guard-dangerous.mjs` の
  誤検知を直そうとしたら guard 自身がその修正をブロックした。承認ファイルは実行中コンテナ内に
  置かれるため、ローカルで承認を発行してもリモートセッションには届かない。IMP-2026-029 で
  3 回再発していた問題の**4 回目**。ここで「承認機構を直す」ではなく**承認機構を撤去して
  PR レビューへ移す**判断をしたのが転換点。
- **差分が -3880 行の削減主体**（PR #125/#126 合計 +967/-3880）。改善＝指示追加ではなく
  削除・移動も含む、という CLAUDE.md の原則がそのまま出た形。
- 承認境界を PR レビューへ移したことで、**リモートのエフェメラル環境でも構成ファイルを
  触れるようになった**。人間の確認は PR 差分とマージ判断に集約される。
