## 気づき・メモ

- **dev サーバー起動の注意**：`pnpm --filter @cookpit/web dev --webpack` で起動する。
  - 素の `pnpm dev`（Turbopack）は `next.config.ts` の `withSerwist`（webpack 設定）と競合してエラーになる
  - 恒久対処案：`next.config.ts` に空の `turbopack: {}` を追加（未対応・今後の検討事項）
- **Next.js RSC の学び**：App Router は全コンポーネントがデフォルト Server Component。`useState`/`useMemo` 等の hooks を使うファイルは冒頭に `'use client'` 必須。ファイル名に `client` と付けても無関係（宣言だけが判定基準）
- **Codex 生成コードの頻出ミス**（今回フロントで再確認）
  - Tailwind クラス名のタイポは `tsc` を通過するため目視・実画面確認が必須
  - props で受けた `onClick`/`onChange` をハンドラ要素に結線し忘れる
  - 差し戻し時、複数行 diff の一部だけ取り込んで残りを反映し損ねる → 再レビュー必須
- **作成フォームの設計判断（合意済み）**
  - 材料の「少々・適量」（`amountNote`）は「量」フィールドにテキストも許可する方式。送信時に数値判定 → `amountValue`+`amountUnit` か `amountNote` に振り分け（変換ロジックは `buildCreateInput` に集約）
  - 保存成功後は `/recipes` に戻る（`router.push` + `router.refresh()`）。詳細画面が未実装のため
  - 単位プルダウンはネイティブ `<select>`（モバイル PWA の OS 標準ピッカー・実装コスト最小）
  - タグは複数選択（一覧フィルタの単一選択とは異なる）
  - 書き込みは Hono RPC 経由（`client.api.recipes.$post`）。TanStack Query は MVP1 では導入しない
