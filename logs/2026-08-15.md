## 気づき・メモ

- 8/10 の「環境変数登録済み」は Production には効いていなかった。後続の本番デプロイが何度か走っても vapid は 500 のままだった。Preview だけ、または Redeploy 前、で止まっていた可能性が高い
- Cron の 500 は 2 種類ある。未設定は `{ error: "Server misconfigured" }`。`setVapidDetails` の throw は `app.onError` 経由の `{ error: "Internal Server Error" }`。後者は Logs を見ないと原因が分からない
- `VAPID_SUBJECT` は `mailto:` か `https://` のみ。メールアドレスだけ入れるとサーバー側で先に落ちる（Apple の 403 まで到達しない）
- `pnpm exec web-push` はローカル `node_modules` にバイナリが無いと失敗する。鍵生成は `pnpm dlx web-push generate-vapid-keys`
- Preview は Deployment Protection（SSO）があり、iPhone PWA での確認が重い。今日は本番で完了条件を確認した（試験計画 §10 の Preview 専用鍵とは経路が異なる）
- 試験計画 MB-01〜14 の全文は未消化。Android 対照（MB-08b）は `BLOCKED`（実機なし）。完了条件は通知受信で満たした
