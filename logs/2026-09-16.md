## 気づき・メモ

- **公開は ADR-0003 の前提を壊す変更だった。** 決定理由 5「Vercel URL の推測難度はそこそこ高い」
  が唯一の防御で、リポジトリ名から本番 URL が自明に導けるため URL の記述を消しても意味がない。
  「リポジトリの中身が安全か」ではなく「公開が防御を消すか」を見るのが本質だった。
- **fail-closed は `NODE_ENV` で判定する。** Vercel の Preview デプロイも `NODE_ENV=production`
  で動くため、`VERCEL_ENV === 'production'` で判定すると Preview が素通りして穴になる。
- **`/manifest.webmanifest` は認証除外が必須。** ブラウザが credentials なしで取得するため、
  保護すると 401 で PWA のインストールが壊れる。
- **環境の事実（恒久）**: リモート実行環境は egress 遮断で本番 URL へ到達できない。
  `docs/07-dev-rules.md` §環境の既知の事実 への追記を次回判断する（前日から持ち越し）。
- **ローカル `next start` の black-box は本番の保証にならない。** Vercel の proxy は同じ正規表現
  文字列を別エンジンで評価する。ADR-0021 の移行手順に本番での再確認 6 本を必須として入れた。
- **turbo のキャッシュ再生を実行結果と誤認しかけた（本日 2 回）。** `cache hit, replaying logs` /
  `FULL TURBO` が過去の結果を PASS として出す。`--force` で流し直して実実行に置き換えた。
  品質ゲートが「実際に実行されたか」を保証していない問題として改善バックログへ昇格。
- Fable がクレジット上限（HTTP 429）で停止。`orchestration-policy.md` のフォールバック
  （設計判断をメインの Opus、成果物化を Sonnet）が明文化されていたため手戻りなく続行できた。
- implementer が 95 分無通知で停止し、成果物だけディスクに残った。`offline-write-queue.md` の
  既知パターンと同型で、同ファイルの改善案（`git diff` への機械的検査）を手動実行して引き継いだ。
