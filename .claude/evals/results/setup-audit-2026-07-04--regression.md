### C1: CLAUDE.md 減量

**懸念 (a): 04-domain-model 全文購読を外したことで設計・実装の文脈が欠落しないか**

対象集約のセクションのみ読む運用への変更は、以下の構造的理由により各ケースで問題なし。

- small-bug-fix (L1): Recipe Entity/VO のバグ修正。Recipe 集約セクションのみで必要な文脈が揃う。
  L1 で orchestrator を使わない場合も、修正対象のファイルパスが明確なため対象外セクションの
  文脈は不要。
- api-field-addition (L2): Recipe.servings 追加。Recipe 集約セクションのみで足りる。
- database-schema-change (L3): Recipe.status 追加。同上。

重要な緩和要因: CLAUDE.md のセッション開始制約（「対象集約のセクションのみ」）は
**ベースセッション**に適用される。subagent（orchestrator, requirements-analyst,
architecture-designer）の定義には同制約はなく、各 agent の定義が
`docs/04-domain-model.md` を無制限に参照するよう指示している。設計・影響範囲分析を
行う agent は full 04 へのアクセスを保持しており、コンテキスト欠落の構造的リスクは低い。

リスクの残存範囲: 単一ベースセッション（非 Orchestrator パス）での複数集約にまたがるタスク。
ただし本評価の 3 ケースはすべて単一集約（Recipe）であり、この評価ではそのリスクは顕在化しない。

`docs/07-dev-rules.md` の必読から `.claude/rules/coding-standards.md` への変更:
implementer.md が `.claude/rules/` を直接参照しているため実効性に変化なし。

```javascript
const LOG_STALE_DAYS = 3;
```

1. **定性評価のみ**: 実コード実行・実 Agent 起動なし。Agent 定義・Hook・CLAUDE.md・ドキュメントの
   プロンプトレビューに基づく推論。モデルの実際の動作品質は含まれない。
2. **C3 モデル更新の確認限界**: sonnet-5 の実動作が sonnet-4-6 と同等以上であることは
   定性推定。実際のモデル応答品質・指示遵守率の変動は本評価に含まれない。
3. **単一集約ケースへの限定**: 3 ケースはすべて Recipe 集約を対象とする。C1（04-domain-model
   targeted reading）のリスクが顕在化する「複数集約にまたがるタスク」は本評価の対象外。
4. **スコアの離散性**: 1 点単位のスコアであり、C4 の小幅正方向効果のような「0.3 点相当」の
   改善は反映できない。
5. **meta-docs の陳腐化**: active docs への sonnet-4-6 残存参照を確認したが、タスク実行品質
   への影響はないと判断した。将来の保守リスクとして記録した。
