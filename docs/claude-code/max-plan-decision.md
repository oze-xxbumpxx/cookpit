# Max プラン移行判断（2026-07 〜 2026-08）

Pro → Max（$100/月・5倍枠）へ変更するかを、観測データに基づいて判断するための記録。
判断期限は **2026-08-08**（リマインダー設定済み。それ以前に基準を満たしたら前倒しで判断してよい）。

## 背景（2026-07-18 時点の事実）

- **7/20 から Fable 5 が全 Max プランに含まれる**（上限の 50% 枠 = Fable は通常モデルの
  半分の枠でカウント）。Max の料金は据え置き（$100 = Pro の 5 倍枠 / $200 = 20 倍枠）。
- **Pro は従量クレジット経由での Fable 利用が継続**。一回限りの $100 クレジットが付与される。
- 出典: [Claude 公式アナウンス](https://x.com/claudeai/status/2078302415804379218) /
  [Max プラン Help](https://support.claude.com/en/articles/11049741-what-is-the-max-plan)

## 判断基準

2〜3 週間（7/20 〜 8/8）の観測で、次のいずれかを満たしたら **Max $100 へ変更**する。

1. $100 クレジットの消費ペースが **月換算 $80 以上**（= 2 週間で $40 以上減）
2. Pro の 5 時間セッション上限に **週 2 回以上**到達
3. Fable を使いたい場面でクレジット残を理由に **Opus へ妥協することが常態化**

いずれも満たさない（クレジット消費が月換算 $50 未満・上限到達がほぼ無い）なら **Pro 継続**。
中間なら、もう 2 週間観測を延長するか、利用頻度の見通しで決める。

> Max 5x での Fable 体感枠は「Pro の 2.5 倍相当」（50% 枠のため）。移行後に週次上限へ
> 頻繁に当たるようなら、その時点で $200（20x）を検討する。二段階で判断し、最初から
> 20x にはしない。

## 併走するコスト対策（プランに関わらず実施）

Subagent のモデル采配は実装済み（各 `.claude/agents/*.md` の frontmatter。正典:
[orchestration-policy.md](./orchestration-policy.md) §モデル割り当て）。残る実効化ポイントは
**メインセッションのモデル選択**で、これは人間が `/model` で行う。

- 単発の質問・軽い調査のセッション → **Sonnet** で開始する
- 通常の開発タスク（orchestrator・L1/L2）→ **Opus**（既定）
- **Fable は L3 の方針決め・重大トレードオフ・最終確認に限定**。セッション全体を
  Fable で回さない（Fable は 50% 枠のため消費が実質 2 倍）
- 探す・見比べるだけの作業は `Explore`（`model: haiku`）へ委譲されているかを
  orchestrator の挙動で確認する（禁止事項リスト参照）
