document-reviewer はログ言及が各 1 程度だが定義と起動条件の維持コストが残る。

| 事象 | 再現タスク | 累計回数 | 昇格条件 |

## 原因

IMP-006 で委譲ギャップ埋めとして追加されたが、その後の Codex 委譲化で前提が変わった。

## 変更案

| 吸収元 | 吸収先 |
| --- | --- |
| requirements-analyst | orchestrator（調査）+ architecture-designer（requirements 保存） |
| performance-designer | architecture-designer（条件付き性能節） |
| e2e-test-implementer | implementer（条件付き E2E 実装）※監査案の test-designer からツール適合で変更 |

security-reviewer は単独維持。吸収元ファイルは `.claude/agents/archive/` へ移設。
