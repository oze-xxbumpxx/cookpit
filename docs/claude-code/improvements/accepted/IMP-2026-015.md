# IMP-2026-015: close-session ナッジの「記録なし」部分一致誤検出を完全一致化

> Hook 変更のため人間承認必須。meal-plan-core 候補の事象 1 を本適用。

- **ステータス**: accepted
- **対象 Agent または Skill**: Hook: `.claude/hooks/check-improvement-cycle.mjs`
- **承認区分**: 人間承認必須（Hook の判定条件変更）
- **起票日**: 2026-07-08
- **採用日**: 2026-07-08
- **元候補**: [candidates/meal-plan-core.md](../candidates/meal-plan-core.md)（事象 1）

## 背景

`timeUnrecordedNudge()` が所要時間セクション内の「記録なし」を部分一致で判定していたため、
「約 30 分（…先行セッションは記録なし）」のような**記録済み＋注記**行を未記録と誤判定し、
close-session ナッジが誤発火した（2026-07-06・meal-plan-core）。

## 変更内容

- セクション本文を trim した非空行を結合し、次のいずれかなら未記録:
  - 空
  - 本文がちょうど `記録なし`
  - 本文がちょうど `[作業時間]`
- 時間表現（`/\d+\s*(分|時間|h)\b/i`）があれば記録済みとみなす（注記に「記録なし」があっても発火しない）。

## 評価（スモーク）

| #   | 入力（所要時間セクション）              | 期待       | 結果 |
| --- | --------------------------------------- | ---------- | ---- |
| 1   | `約 30 分（…先行セッションは記録なし）` | 発火しない | PASS |
| 2   | `記録なし` のみ                         | 発火       | PASS |
| 3   | `[作業時間]` のみ                       | 発火       | PASS |
| 4   | 空                                      | 発火       | PASS |
| 5   | `約3時間50分（自動推定…）`              | 発火しない | PASS |

## ロールバック

`timeUnrecordedNudge()` を部分一致（`/記録なし|\[作業時間\]/`）に戻す。
