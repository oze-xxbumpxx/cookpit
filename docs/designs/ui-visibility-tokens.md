## 背景（測定で裏取り）

「温かいキッチン」パレットは配色は良いが、**副次テキストと枠線のコントラストが不足**して
「見えにくい」原因になっていた。WCAG コントラスト比（AA 通常テキスト = 4.5:1）で計測:

| トークン                                                | 変更前    | 比     | 判定               |
| ------------------------------------------------------- | --------- | ------ | ------------------ |
| `muted-foreground`（日付・ラベル・空状態・placeholder） | `#8A7F73` | 3.6:1  | ✗ AA 不足          |
| `border`（カード/入力の輪郭・vs card）                  | `#ECE3D6` | 1.27:1 | ✗ 輪郭がほぼ不可視 |
| `primary` + 白文字（ボタン）                            | `#D8552F` | 3.99:1 | △ 境界             |

セマンティックトークンのため、`:root` の値是正だけで**全画面（既存画面含む）に自動反映**する。

## ボトムナビゲーション + 文言（実装済み・2026-07-21）

ユーザー指摘「今どの画面にいるか分かりづらい（タブに現在地表示がない）」「リッチにしたい」
「日本語の言い回し（捨てる 等）」への対応。

- **現在地の問題**: 各画面が独自のヘッダーに不揃いなクロス導線リンクを持つだけで、`usePathname`
  未使用 = **アクティブ表示ゼロ**だった。
- **共有ボトムタブバー** `app/_components/nav-bar.tsx`（`'use client'`・`layout.tsx` で全画面に描画）:
  ホーム / 献立 / 買い物 / 在庫 / レシピ の 5 タブ。lucide アイコン（House / CalendarDays /
  ShoppingCart / Refrigerator / ChefHat）で料理っぽさとリッチさを付与。`usePathname` で現在地を
  primary 色 + `aria-current="page"` 表示（詳細ページは親セクションを startsWith 判定でアクティブ）。
- **ヘッダー整理**: 各画面のヘッダーから重複クロス導線を撤去し、タイトル + 画面固有アクション
  （履歴 / 追加 / 更新 等）のみに簡素化。導線はボトムナビへ一元化。
- **固定ナビに隠れない余白**: `globals.css` の `main` に `padding-bottom` を追加（全画面一括）。
- **文言修正**: 在庫の「捨てた」→「**廃棄**」（「捨てる」の直截さを避け在庫操作として自然な語へ）。
  - **追記（2026-07-25）**: さらに「使った」→「**消費**」に変更し、2 ボタンを名詞で揃えた
    （旧: 動詞の過去形「使った」＋名詞「廃棄」で品詞が不揃いだった）。あわせて lucide アイコンを
    付与（消費: `Utensils` / 廃棄: `Trash2`）し、廃棄ボタンを `variant="destructive"`（赤の塗り）から
    `outline` + 赤の文字色（`text-destructive/80`）へ弱めた。取り消せない操作のため色の手がかりは
    残しつつ、赤の塗りは本当に危険な操作のために温存する判断（ユーザー確定・2026-07-25）。
- テスト: `nav-bar.test.tsx`（タブ href・アクティブ判定 4 件）追加。ヘッダー導線・文言の
  既存テストを新仕様へ更新。品質ゲート type-check 5/5 / lint 0 error / web 327 テスト PASS。
- 実画面確認（`dev:pglite` + Playwright）: 在庫/ホーム/レシピでアクティブタブ・アイコン・
  余白・「廃棄」ボタンを確認。
- **既知の IA トレードオフ**: タブは 5 枠のため「商品」はタブ外（ダッシュボードのメニューから到達）。
  商品画面ではアクティブタブが点かない。必要ならタブ構成の見直し可。

## 見出しフォント（実装済み・2026-07-21）

見出しと本文が同一書体（sans）で階層が弱く、料理らしさも無かった。丸ゴシックの
**Zen Maru Gothic** を見出し（`h1/h2/h3`）に適用し、温かみ・料理らしさと階層を出す。

- **配信方法**: `next/font/google` は日本語サブセット非対応（`Zen Maru Gothic` の subsets に
  `japanese` が無い）ため、**Fontsource（`@fontsource/zen-maru-gothic`）で自ホスト**。
  日本語 woff2 を同梱するのでオフライン・クロスデバイスで一貫。
- **読み込み最小化**: 見出しは `font-semibold`（→ 700 にマップ）のため **weight 700 のみ**読み込む
  （日本語 woff2 は 1 ウェイト約 1.5MB。Service Worker キャッシュ対象）。
- `globals.css` の base で `h1,h2,h3` の `font-family` を `'Zen Maru Gothic', 'Hiragino Maru Gothic
ProN', sans-serif` に。本文は sans のまま（階層のコントラスト）。
- 実画面確認（`dev:pglite` + Playwright）: ダッシュボード・レシピの見出しが丸ゴシックで描画。
  品質ゲート type-check 5/5 / lint 0 error / web 327 テスト PASS。

## エラー配色のトークン化（実装済み・2026-07-21）

エラーバナー・必須/入力エラーが `red-200/red-50/red-700/red-600` を直書きしており、温かい
パレットから浮いていた。**全 15 ファイルを `destructive` トークンへ統一**:

- バナー: `border-red-200 bg-red-50 text-red-700` → `border-destructive/30 bg-destructive/5 text-destructive`
  （`bg-destructive/5` は背景 #FAF6F0 上で text-destructive とのコントラスト 4.7:1 ✓）。
- 入力/必須エラー: `text-red-600` → `text-destructive`（#C0392B・背景で 5.05:1 ✓）。
- 実画面で描画確認（Tailwind v4 が `bg-destructive/5` 等を color-mix で生成）。品質ゲート
  type-check 5/5 / lint 0 error / web 327 テスト PASS。

## ダークモードの温かい配色化（実装済み・2026-07-21）

従来 `.dark` は素の shadcn グレー（oklch 無彩色）でライトの温かいパレットと不整合、かつ
テーマ切替 UI が無く到達不能だった。以下で解消:

- **暖色ダークパレット**: `.dark` の全トークンをエスプレッソ地（`#221E1A`）+ クリーム文字
  （`#ECE4D8`）+ 明るめテラコッタ（primary `#E0603A`・文字は暗色）へ置換。全ペア AA 準拠
  （muted-foreground 7.0:1 / primary+暗字 4.65:1 / border 輪郭 1.8:1）。
- **OS 追従**: `layout.tsx` に描画前インラインスクリプトを追加し、`prefers-color-scheme: dark` に
  応じて `.dark` を付与（`matchMedia` の change も購読）。切替 UI 無しで端末のダーク設定に自動追従。
  `<html suppressHydrationWarning>` でハイドレーション差分を抑制。ブラウザ chrome 色も
  `themeColor` を light/dark で出し分け。
- アプリ内 `dark:` ユーティリティは不使用（色は全てトークン）＝ `.dark` のトークン置換だけで全画面反映。
- カテゴリチップは bg/text をセットで持つ自己完結色のため両テーマで可読（ダークでは明るいチップとして映える）。
- 実画面確認（`emulateMedia colorScheme=dark`）: ダッシュボード/レシピでエスプレッソ地・クリーム見出し・
  テラコッタのアクティブタブ・カード境界を確認。品質ゲート type-check 5/5 / lint 0 error / web 332 テスト PASS。

## カテゴリ配色 + カードの質感（実装済み・2026-07-21）

- **中央集約の配色 util** `app/_utils/category-color.ts`: レシピタグ（主菜/副菜/汁物/作り置き向き/
  冷凍可）と商品カテゴリ（野菜/肉/魚/調味料/乾物/冷凍/その他）を、彩度を抑えた食材連想色に
  マッピング（肉=rose / 野菜=olive / 魚=teal / 調味料=amber / 冷凍=blue / 乾物=brown / その他=neutral）。
  **色はこの util だけに置く**（#2 の red 直書き解消と同じ方針）。全ペア AA(>=4.5:1) 準拠。
- 適用: `recipe-card` のタグ（従来は index 依存の暫定色）・`product-card` のカテゴリバッジ（従来は一律 accent）。
- **カードの質感**: レシピ/商品カード・在庫行に `shadow-sm` + hover の軽い lift を付与し奥行きを出す。
- util の単体テスト（既知/未知の写像・4 件）。品質ゲート type-check 5/5 / lint 0 error / web 331 テスト PASS。
- 実画面確認: 商品（野菜=緑/肉=ロゼ/調味料=琥珀）・レシピ（主菜/汁物/冷凍可 等）で色分け・影を確認。
