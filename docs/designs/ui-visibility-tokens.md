## 背景（測定で裏取り）

「温かいキッチン」パレットは配色は良いが、**副次テキストと枠線のコントラストが不足**して
「見えにくい」原因になっていた。WCAG コントラスト比（AA 通常テキスト = 4.5:1）で計測:

| トークン                                                | 変更前    | 比     | 判定               |
| ------------------------------------------------------- | --------- | ------ | ------------------ |
| `muted-foreground`（日付・ラベル・空状態・placeholder） | `#8A7F73` | 3.6:1  | ✗ AA 不足          |
| `border`（カード/入力の輪郭・vs card）                  | `#ECE3D6` | 1.27:1 | ✗ 輪郭がほぼ不可視 |
| `primary` + 白文字（ボタン）                            | `#D8552F` | 3.99:1 | △ 境界             |

セマンティックトークンのため、`:root` の値是正だけで**全画面（既存画面含む）に自動反映**する。

## Phase B（提案・統一）

- **ダークモードの温かい配色化**: 現状 `.dark` は素の shadcn グレー（oklch 無彩色）のままで
  ライトの温かいパレットと不整合。ただし現状はテーマ切替 UI が無く `.dark` は到達不能のため、
  切替導入とセットで対応するか、後回し可（要判断）。
- **見出しフォント（`--font-heading`）の差し替え**: 現状 `--font-heading` = `--font-sans`（Geist）で
  見出しと本文が同一。温かみのある書体で階層を明確化（料理っぽさにも寄与）。
  候補: 丸ゴシック系（日本語対応・親しみやすさ）。next/font での読み込みコストを確認して確定。
