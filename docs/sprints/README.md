# docs/sprints

スプリントレビューと、完了済み Sprint 1 計画の置き場。

| パス                           | 用途                                                 |
| ------------------------------ | ---------------------------------------------------- |
| `sprintN-review-YYYY-MM-DD.md` | 週次スプリントレビュー（現行・ロードマップから参照） |
| [`archive/`](./archive/)       | 完了済み Sprint 1 の実装計画・ガイド（履歴）         |

新しい週次レビューは直下に置く。Sprint 1 当時の実装計画は `archive/` を参照する。
